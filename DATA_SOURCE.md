# Data source and permitted use

This project uses the **Telecom Customer Churn** sample data published by Maven Analytics.

- Official source: https://mavenanalytics.io/data-playground/telecom-customer-churn
- Original source identified by Maven Analytics: IBM Cognos Analytics
- License stated on the official data page: **Public Domain**
- Scope: fictional telecommunications customers in California
- Tables used: customer churn, ZIP-code population, and the data dictionary

The raw CSV files are included so the analysis is reproducible. They contain fictional sample records, not Telnor customer data or information from Aarón's professional work.
